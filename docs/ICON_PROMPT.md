# Icon generation record

Mode: built-in `imagegen` tool, new image, opaque background, no reference images.
Saved project asset: `assets/images/beaver-icon.png`. The same original image is
used for Godot's project icon and normal/adaptive Android launcher artwork.
The monochrome launcher fallback is a separate repo-native silhouette SVG.

Exact final prompt:

> Create a premium photorealistic Android game app icon, square 1024x1024, no text, no lettering, no borders. Tight heroic three-quarter portrait of a real North American beaver looking proudly toward the upper right, chin lifted, confident dignified expression, clearly beaver not otter: rounded ears, broad muzzle, orange incisor teeth subtly visible, glossy dark eyes, extremely detailed natural wet brown fur, powerful chest. Cinematic warm sunrise rim light on fur, cool deep teal forest shadows, soft misty forest and river background, dramatic photographic wildlife realism. Strong readable silhouette at small icon size, face centered within middle 70 percent safe area, very high-quality actual wildlife photography aesthetic, no cartoon, no illustration, no human clothing, no weapons. Save the generated result as project asset for beaver-mayhem.

Output was visually inspected, copied into the repository, and the actual exported
Android launcher WebP was extracted and visually checked after the build.
